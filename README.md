# quantrank500-web

The public website of **QuantRank500** — a free, open-source platform that
records stock predictions before the market opens and settles them against
actual exchange trade records.

- Live: [quantrank500.com](https://quantrank500.com)
- Static HTML, no frameworks, no build step. GitHub Pages serves this
  repository as-is.

**Status:** in development. The settlement engine is built and validated
against real market history; public beta opens when validation completes, and
the platform code will be open-sourced at launch.
