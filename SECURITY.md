# Security

QuantRank500 is a trust platform; security reports are taken seriously and
gratefully.

**To report a vulnerability:** email
[security@quantrank500.com](mailto:security@quantrank500.com), or use GitHub's
private reporting — the **Security → Report a vulnerability** tab on this
repository (or any QuantRank500 repository). Please do not open a public issue
for security problems before they are fixed.

You can expect an acknowledgment within a few days. This is a solo-maintained,
free project — fixes ship as fast as one person can responsibly ship them.
